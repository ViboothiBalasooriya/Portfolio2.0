# 👋 Welcome to Viboothi's Portfolio 3.0

Hey there! Welcome to the source code for my personal portfolio. I built this to be a cinematic, brutalist-inspired experience that breaks away from boring traditional grids. It’s all about high-contrast monochrome aesthetics, smooth animations, and telling a story through code.

## ✨ What's Inside?

- **Pure Monochrome Aesthetic:** We ditched the colors! A strict black, white, and subtle grey palette ensures maximum impact and a premium feel.
- **Buttery Smooth Animations:** Powered by **GSAP** and **Framer Motion**. Watch out for the crazy "O" zoom reveal in the hero and the seamless horizontal right-to-left slide when you hit the footer!
- **Headless CMS Backend:** The content is fully dynamic! Integrated with **Sanity.io**, allowing instant updates to projects, FAQs, and case studies via a beautiful admin dashboard without touching the code.
- **Cinematic Case Studies:** Full-bleed edge-to-edge layouts with grain texturing.

## 🛠️ The Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS (Vanilla utilities with custom CSS for structural stability)
- **Animations:** GSAP (ScrollTrigger, Flip) + Framer Motion
- **Backend/CMS:** Sanity.io
- **Typography:** Syne & JetBrains Mono

## 🚀 How to Run Locally

If you want to spin this up on your own machine, you'll need two terminal windows (one for the website and one for the admin panel).

**1. Start the React Frontend:**
```bash
# Install dependencies
npm install

# Start the development server (runs on localhost:5173)
npm run dev
```

**2. Start the Sanity Admin Dashboard:**
```bash
# Navigate to the studio folder
cd portfolio-studio

# Start the CMS (runs on localhost:3333)
npm run dev
```

## 🎨 Design Philosophy
- **"The Story" Theme:** Moving beyond fragmented visuals into deeper, narrative-driven design.
- **Texture:** Utilizing CSS-based film grain and optimized image rendering to mask digital upscaling and provide tactile depth.
